# Licencias

| Elemento | Situación actual | Pendiente |
|---|---|---|
| Código | ISC declarada en `package.json`; autor Francois Rojo; **sin archivo LICENSE** | Confirmar la licencia y añadir el archivo |
| Fotos de ingredientes | CC BY, CC BY-SA, CC0, dominio público — [[Imágenes y créditos]] | Mantener créditos; indicar modificaciones |
| Arte y videos del taller | Creados por el autor con OpenArt — [[Arte y videos]] | Confirmar condiciones del plan; declarar condición |
| Textos de fichas | Redacción del proyecto con fuentes citadas | Elegir licencia (sugerida CC BY-SA 4.0) |
| Ilustración de Bruma | SVG propio | Decidir si se reserva como marca |
| Dependencias | React, Vite y Phosphor (MIT), three (MIT), SDK de Google (Apache-2.0) | Verificar con un inventario automático antes de publicar |
| Rasgos de NC State Extension, EMA, MINSAL | Citados y resumidos | Revisar que sean resúmenes y no copias |

Una licencia permisiva de código y fotos con «compartir igual» pueden convivir en el mismo repositorio: cada recurso conserva la suya, siempre que quede indicado archivo por archivo.
