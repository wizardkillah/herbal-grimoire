# Vinagre de manzana

**Identidad:** Vinagre de manzana
**Parte o presentación:** Base ácida
**Categoría documental:** Base de preparación

## Resumen
Sidra fermentada hasta ácido acético. Sirve como disolvente ácido para macerar plantas.

## Precaución
Es ácido: sin diluir puede irritar. Esta ficha no le atribuye efectos terapéuticos.
