# Agua 85°C

**Identidad:** Agua potable a 85 °C
**Parte o presentación:** Base acuosa
**Categoría documental:** Base de preparación

## Resumen
Temperatura intermedia, habitual para tés semioxidados y muchas flores.

## Precaución
La IARC clasifica como probablemente cancerígeno para el esófago el consumo de bebidas muy calientes, por sobre 65 °C. Deja entibiar antes de beber.
