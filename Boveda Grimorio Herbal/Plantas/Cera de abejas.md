# Cera de abejas

**Identidad:** Cera producida por las abejas
**Parte o presentación:** Base grasa
**Categoría documental:** Base de preparación

## Resumen
Da cuerpo a ungüentos y bálsamos al fundirse con aceites.

## Precaución
Es una base para preparados de uso externo, no un ingrediente para beber.
