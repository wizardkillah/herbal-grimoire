# Lavanda

**Identidad:** Lavandula angustifolia
**Parte o presentación:** Flores
**Categoría documental:** Uso tradicional

## Resumen
La monografía europea recoge preparados florales de uso tradicional para síntomas leves de estrés y como ayuda para dormir.

## Precaución
Las flores y el aceite esencial son preparaciones distintas; no se pueden intercambiar sus usos.
