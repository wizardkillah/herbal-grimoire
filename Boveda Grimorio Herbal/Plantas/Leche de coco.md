# Leche de coco

**Identidad:** Extracto acuoso de la pulpa del coco
**Parte o presentación:** Base vegetal
**Categoría documental:** Base de preparación

## Resumen
Base grasa y cremosa que se obtiene de la pulpa rallada del coco.

## Precaución
Es una base culinaria. Esta ficha no le atribuye efectos terapéuticos.
