# Agua potable

**Identidad:** Agua potable
**Parte o presentación:** Base acuosa
**Categoría documental:** Base de preparación

## Resumen
Representa el agua apta para consumo usada como base. Sustituye al antiguo ingrediente de fantasía.

## Precaución
Agua de montaña, lluvia o rocío no equivale a agua potable.
