# Hielo

**Identidad:** Agua potable congelada
**Parte o presentación:** Base acuosa
**Categoría documental:** Base de preparación

## Resumen
Enfría y diluye las preparaciones.

## Precaución
El hielo debe hacerse con agua potable: congelar no la purifica.
