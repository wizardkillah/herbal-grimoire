# Historia de versiones

| Versión | Qué era | Dónde quedó |
|---|---|---|
| Vanilla | Página HTML única | `index_vanilla_backup.html` |
| v7 | Componente React monolítico con chat Gemini en el cliente | `src/grimorio_herbal_v7.jsx` |
| v8 | Reorganización en componentes, rutas, XP, mascotas | `src/GrimorioHerbalV8.jsx`, `src/components/`, `src/data/`, `src/hooks/`, `src/services/gemini.js` |
| Taller actual | Motor local con pruebas, herbolario documentado, respaldo, Bruma en servidor | `src/game/` |
| Plan v9 | Minijuegos de naturaleza; fase A implementada | `docs/PROMPT_MAESTRO_Minijuegos_v9_Adaptado.md` |
